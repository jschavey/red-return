# Red Return

> Become the planet.

A satirical landing page for a luxury startup that composts billionaires and ships them to Mars to "terraform" it. Live at **https://jschavey.github.io/red-return/**.

Red Return is satire. The company, its founder (Dax Valtor), and the products are fictional. Nothing on the page collects payment or personal information. The "Reserve" button only shows a joke message.

## Running it

It's one static file, `index.html`, with no build step. Open it in a browser, or serve the folder:

```
python3 -m http.server
```

Pushing to `main` publishes the site through GitHub Pages.
